## Contract ของกราฟและเหตุการณ์

เป็น `SYNTHETIC_DEMO` เท่านั้น ซ่อนในโหมดแผนติดตั้ง การเปลี่ยนหมุด เปลี่ยนฉาก เล่น/เลื่อนเวลา และเริ่มใหม่ ต้องเปลี่ยนหลักฐานให้ตรงกัน ไม่มีเหตุการณ์จากอนาคตหลังเวลาที่เลือก

กราฟแยกหน่วย PM2.5 (µg/m³) และ CO (ppm) เส้นประคือเกณฑ์เดโมของแต่ละค่า ไม่ใช่เกณฑ์แจ้งเหตุที่สอบเทียบแล้ว ต้องให้ทั้งสองค่าผ่านต่อเนื่องตาม `core.reading()` จึงขึ้น SUSPECT. จุดเริ่มฉากไม่ใช่ต้นเพลิงที่คำนวณย้อนกลับ ข้อมูลขาดเป็นช่องว่าง ไม่ใช่ค่าศูนย์

การรับทราบไม่ใช่ยืนยันไฟ ไม่ส่งแจ้งเตือนภายนอก ไม่เก็บในฐานกลาง และไม่แต่งเวลา acknowledgment ที่แอปไม่ได้บันทึก เมื่อเปลี่ยนฉากหรือเริ่มใหม่ สถานะรับทราบต้องรีเซ็ต

`history.js` ใช้ `WildfireCore.reading()` เดียวกับหน้าหลักและ `WildfireApp.getState()` แบบ read-only. สังเกตเฉพาะการแทนที่ children ระดับแรกของ `#details`; การวาดกราฟในบล็อกย่อยไม่ทำให้เกิดวงวน ไม่มี backend ใหม่หรือ dependency ภายนอก

## พิกัดและการทำนาย

8 หมุดเป็นพิกัดอ้างอิงสำรวจตามแนวกึ่งกลางถนน ไม่ใช่ฐานรากสำหรับติดตั้งบนผิวจราจร ต้องเลือกไหล่ทางที่ปลอดภัยหลังสำรวจแดด/การเข้าถึง/สิทธิ์ติดตั้งและสัญญาณจริง ริมถนนไม่ได้รับประกันไม่มีเงาต้นไม้หรือภูเขาบัง

รุ่นนี้เป็นแอปออกแบบและจำลอง ยังไม่มี sensor feed จริงหรือการสอบเทียบแนวไฟลาม ไม่ได้พิสูจน์ว่าเครือข่ายริมถนนจะตรวจไฟได้ทุกจุด โดยเฉพาะช่องว่างด้านเหนือ–ใต้ รายละเอียดและ power budget อยู่ใน [DESIGN.md](DESIGN.md)

## ตรวจสอบ

`node --test tests/*.test.cjs` ตรวจข้อมูลแผน พลังงาน และประวัติจำลอง. หลัง build และเปิด HTTP server แล้ว `python tests/browser.py` ตามด้วย `python tests/history_browser.py` ตรวจการเลือกหมุด กราฟสองหน่วย เหตุการณ์ ขาดข้อมูล รับทราบ/รีเซ็ต และมือถือ. ผลทดสอบกับผล deploy เป็นคนละสถานะ
